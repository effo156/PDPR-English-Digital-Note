# PDPR English Digital Note

Interactive revision notes for PDPR English, Form 1 (Wild Weather) and Form 2 (Smart Money).
Two days per form, access codes, a 60-minute session and a result card students screenshot for Google Classroom.

Open `index.html` in a browser, or use the GitHub Pages link of this repository.
